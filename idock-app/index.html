So geht's

In einer Minute verbunden.

  1. Installieren

    Den Newcall Launcher laden, öffnen und bei iDock auf „Installieren“ klicken. Zeigt Windows „Der Computer wurde geschützt“, auf „Weitere Informationen“ und „Trotzdem ausführen“ klicken.

  2. QR-Code scannen

    iDock zeigt einen QR-Code. Mit der iPhone-Kamera scannen, die PIN eingeben – fertig gekoppelt.

  3. Zum Home-Bildschirm

    In Safari auf „Teilen“ → „Zum Home-Bildschirm“. Ab jetzt startet iDock wie eine App. Keine App Store-Installation nötig.
