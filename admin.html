So funktioniert's
  • Anklicken wählt einen Teil der Seite aus (rot umrandet). Rechts kannst du ihn dann bearbeiten.
  • Doppelklick auf einen Text: direkt auf der Seite tippen. Enter = fertig, Shift+Enter = neue Zeile, Esc = abbrechen.
  • ↑ / ↓ verschiebt den ausgewählten Teil, Ausblenden versteckt ihn (im Editor blass, auf der Website unsichtbar).
  • „Übergeordnet“ wählt den ganzen Bereich drumherum – so verschiebst du komplette Abschnitte.
  • Neuer Block fügt unter dem ausgewählten Teil eine Überschrift, einen Text, einen Knopf, ein Bild oder eine Linie ein.
  • Erst Speichern macht die Änderungen auf der echten Website sichtbar. Links und Knöpfe funktionieren im Editor absichtlich nicht.
  • Bereiche, die automatisch gefüllt werden (Songs, Preise, Konto), kannst du verschieben oder ausblenden – ihren Inhalt änderst du unter „Musik“ bzw. mit dem Song-Skript.
